This doc details what emitters will generate for long-running operations.

## Resource create or replace

Long-running operation to create or replace a resource.

<ClientTabs>

```typespec
alias ResourceOperations = global.Azure.Core.ResourceOperations<NoConditionalRequests &
  NoRepeatableRequests &
  NoClientRequestId>;

/** Details about a user. */
@resource("users")
model User {
  /** The name of user. */
  @key
  @visibility(Lifecycle.Read)
  name: string;

  /** The role of user */
  role: string;
}

// Operation for polling the status of the LRO. SDK may exclude this operation from client.
@sharedRoute
op getOperationStatus is ResourceOperations.GetResourceOperationStatus<User, never>;

/** Create or replace the User. */
@pollingOperation(getOperationStatus)
op createOrReplace is ResourceOperations.LongRunningResourceCreateOrReplace<User>;
```

```python
def begin_create_or_replace(
    self, name: str, resource: Union[User, JSON, IO[bytes]], **kwargs: Any
) -> LROPoller[User]
```

## Resource action

<ClientTabs>

```typespec
alias ResourceOperations = global.Azure.Core.ResourceOperations<NoConditionalRequests &

  NoClientRequestId>;

model User {
  /** The name of user. */
  @key
  @visibility(Lifecycle.Read)
  name: string;

  /** The role of user */
  role: string;
}

/** The parameters for exporting a user. */
model UserExportParams {
  /** The format of the data. */
  @query
  format: string;

/** The exported user data. */

op export is ResourceOperations.LongRunningResourceAction<User, UserExportParams, ExportedUser>;
```

## LRO Legacy Decorators

:::caution
The following decorator is in the `Azure.ClientGenerator.Core.Legacy` namespace and should only be used for legacy services with explicit approval. New services should use standard LRO patterns with `@pollingOperation`.
:::

### `@markAsLro`

The `@markAsLro` decorator forces a regular operation to be treated as a long-running operation. The generated method will return a poller type instead of the response directly.

<ClientTabs>

```typespec title="main.tsp"
import "@typespec/http";

using TypeSpec.Http;

@service(#{ title: "Deployment Service" })
namespace DeploymentService;

model DeploymentConfig {
  targetRegion: string;
  instanceCount: int32;
}

model DeploymentResult {
  id: string;
  status: string;
}

@route("/deployments/{deploymentId}")
@post
op startDeployment(@path deploymentId: string, @body config: DeploymentConfig): DeploymentResult;
```

```typespec title="client.tsp"
import "./main.tsp";
import "@azure-tools/typespec-client-generator-core";

using Azure.ClientGenerator.Core.Legacy;

@@markAsLro(DeploymentService.startDeployment);
```

```python
from azure.core.polling import LROPoller

class DeploymentServiceClient:
    def begin_start_deployment(
        self, deployment_id: str, config: DeploymentConfig, **kwargs: Any
    ) -> LROPoller[DeploymentResult]: ...
```

```csharp
public partial class DeploymentServiceClient
{
    public virtual Operation<DeploymentResult> StartDeployment(WaitUntil waitUntil, string deploymentId, DeploymentConfig config, CancellationToken cancellationToken = default);
    public virtual async Task<Operation<DeploymentResult>> StartDeploymentAsync(WaitUntil waitUntil, string deploymentId, DeploymentConfig config, CancellationToken cancellationToken = default);
}
```

```typescript
import { PollerLike, OperationState } from "@azure/core-lro";

export function startDeployment(
  context: Client,
  deploymentId: string,
  config: DeploymentConfig,
  options?: StartDeploymentOptionalParams,
): PollerLike<OperationState<DeploymentResult>, DeploymentResult>;
```

```java
import com.azure.core.util.polling.SyncPoller;

public final class DeploymentServiceClient {
    public SyncPoller<DeploymentResult, DeploymentResult> beginStartDeployment(
        String deploymentId, DeploymentConfig config);
}
```

```go
    ctx context.Context,
    deploymentID string,
    config DeploymentConfig,
    options *DeploymentServiceClientBeginStartDeploymentOptions,

```
