This doc details what emitters will generate for long-running operations.

## Resource create or replace

Long-running operation to create or replace a resource.

<ClientTabs>

```typespec
alias ResourceOperations = global.Azure.Core.ResourceOperations<NoConditionalRequests &
  NoRepeatableRequests &
  NoClientRequestId>;

/** Details about a user. */
@resource("users")
model User {
  /** The name of user. */
  @key
  @visibility(Lifecycle.Read)
  name: string;

  /** The role of user */
  role: string;
}

// Operation for polling the status of the LRO. SDK may exclude this operation from client.
@sharedRoute
op getOperationStatus is ResourceOperations.GetResourceOperationStatus<User, never>;

/** Create or replace the User. */
@pollingOperation(getOperationStatus)
op createOrReplace is ResourceOperations.LongRunningResourceCreateOrReplace<User>;
```

```python
def begin_create_or_replace(
    self, name: str, resource: Union[User, JSON, IO[bytes]], **kwargs: Any
) -> LROPoller[User]
```

## Resource action

## Legacy: Forcing an operation to be treated as an LRO

:::caution
`@markAsLro` is legacy functionality from `Azure.ClientGenerator.Core.Legacy`. Use it only when an operation is not a standard LRO on the service side but must be surfaced as one in client SDKs for backward compatibility. Requires testing to verify end-to-end behavior.
:::

Use `@Azure.ClientGenerator.Core.Legacy.markAsLro` to force an operation to be treated as a Long Running Operation by SDK generators, even when the operation does not follow standard TypeSpec LRO patterns. When applied, generators will produce polling mechanisms and LRO-specific return types.

<ClientTabs>

```typespec
import "@typespec/http";
import "@azure-tools/typespec-client-generator-core";

using Http;
using Azure.ClientGenerator.Core;
using Azure.ClientGenerator.Core.Legacy;

@service(#{ title: "Deploy Service" })
namespace DeployService;

model DeploymentResult {
  id: string;
  status: string;
}

/** Force this operation to be treated as an LRO for backward compatibility */
@markAsLro
@route("/deployments")
@post
op startDeployment(
  @body body: { name: string },
): DeploymentResult;
```

```python
class DeployServiceClient:
    def begin_start_deployment(
        self, body: StartDeploymentRequest, **kwargs: Any
    ) -> LROPoller[DeploymentResult]:
        """Start a deployment. Treated as an LRO.

        :param body: Required.
        :type body: ~deployservice.models.StartDeploymentRequest
        :return: An instance of LROPoller that returns DeploymentResult.
        :rtype: ~azure.core.polling.LROPoller[~deployservice.models.DeploymentResult]
        """
        ...
```

```csharp
public partial class DeployServiceClient

    public virtual async Task<Operation<DeploymentResult>> StartDeploymentAsync(WaitUntil waitUntil, StartDeploymentRequest body, CancellationToken cancellationToken = default);
```
